# Excel-California-Sales-Customer-Behavior-Dashboard
📁 Project Overview

<br>
This project focuses on building a business-driven interactive dashboard in Microsoft Excel using California Superstore data. The goal was to move beyond basic charts and create a dashboard that answers real business questions and supports decision-making.
<br>
<br>


🎯 Objectives:

<br>
To analyze customer behavior, sales trends, and operational performance by transforming raw transactional data into actionable insights through an interactive Excel dashboard. The importanat question answered with this dashboard are:
<br>


1.📈 13-week trend analysis (Sales & Quantity)
<br>
2.🛍️ Product popularity breakdown by customer segments
<br>
3.🌍 Geographic distribution of customers across California
<br>
4.📱 Purchase behavior by channel (App, Website, Instagram, etc.)
<br>
5.🔢 Order frequency distribution
<br>
6.🚚 Shipping time analysis 
<br>
7.😊 Customer satisfaction trends
<br>


⚙️ Tools & Techniques Used

<br>
1.Microsoft Excel
<br>
2.Pivot Tables & Pivot Charts
<br>
3.Slicers for interactivity
<br>
4.Data Cleaning & Transformation
<br>
5.KPI Metrics & Dashboard Design
<br>
<br>


📊 Key Insights

<br>
1.Sales show periodic spikes, indicating demand cycles
2.A small set of products drives the majority of sales
<br>
3.Customers prefer digital channels, especially apps and websites
<br>
4.Most users fall within moderate purchase frequency ranges
<br>
5.Shipping is generally completed within short durations
<br>
6.Customer satisfaction fluctuates across months
<br>
